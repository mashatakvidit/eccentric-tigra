# {эксцентрик тигра} — 10 лет вместе

Некоммерческий юбилейный сайт-подарок аутдор-сообществу «Эксцентрик Тигра» (2016–2026).

Статичная страница без сборки: открыть `index.html` через любой веб-сервер
(например, `python3 -m http.server`) или включить GitHub Pages для ветки `main`.

## Что внутри
- `index.html` — вся страница: 3D-гора с фото по сезонам (three.js), тост с барабаном,
  факты и таймлайн по контуру гор, финал «тигриный язык» со стикерами на физике (matter.js).
- `mountain.js`, `mountain_hi.js` — модель горы (GLB в base64), лёгкая версия для телефонов.
- `t/`, `l/` — превью и крупные версии фото; `bgs_*.jpg` — фоны таймлайна.
- `stk/` — стикеры из набора EccentricTigra.
- `fonts/` — Lebowski by Pragmatica (бесплатная лицензия, см. `fonts/LICENSE-Lebowski.rtf`);
  моноширинные Fragment Mono и Intel One Mono подключаются с Google Fonts.
